# 桌面工作台视觉规范

适用于技术推荐、项目库、资讯库、收藏、来源、任务、设置和详情弹窗。
只支持电脑浏览器，工作区最小宽度 1024px；不增加手机导航、手机样式和手机测试。
布局与样式可调整，API、排序、筛选、收藏、已读、任务及模型配置遵循现有业务契约。

## 字体与颜色

资讯库的发布团队、技术方向和资讯分类使用同一个可收起的矩形筛选面板；面板默认收起，
有已选筛选或从带筛选的链接进入时展开。厂商按国内 / 海外分组，选项使用原生单选控件与自适应多列网格。
已选条件即使收起也继续显示为可清除标签；排序位于面板上方，不藏在面板下方或长下拉分类菜单中。
资讯内容类型使用页面顶部的标签栏，不再使用独立的下拉框。
保持 15px 选项文字、至少 44px 选择行；单选框显式限定 15px 尺寸，不能继承文本输入框的 40px 最小高度。

统一变量定义在 `frontend/src/index.css` 的 `:root`，推荐与项目布局使用 `frontend/src/discovery.css`。
组件颜色引用语义变量，不追加局部颜色字面量或小字号覆盖。Tailwind 的颜色与圆角映射到同一组变量。

| 用途                     | 字号        | 约束                                         |
| ------------------------ | ----------- | -------------------------------------------- |
| 页面主标题               | 30px        | 700 字重，1.3 行高                           |
| 分区标题                 | 20px        | 650 字重                                     |
| 项目和资讯标题           | 18px        | 650 字重，允许长名称换行                     |
| 普通弹窗 / 阅读详情标题  | 20px / 24px | 与分区和正文保持层级，给关闭按钮预留空间     |
| 正文、中文摘要           | 16px        | 1.7–1.85 行高                                |
| 表格内容、输入控件       | 15px        | 不压缩到辅助字号                             |
| 表单标签、按钮、关注理由 | 14px        | 关键动作保持清晰                             |
| 时间、来源、状态、标签   | 13px        | 常规文字的最小字号                           |
| 项目主指标 / 展开指标    | 24px / 20px | 等宽数字；正增长不单独放大，未知与零保持区别 |

字体使用 Inter、Segoe UI、Microsoft YaHei 和系统无衬线回退，不请求外部字体。
字间距为 0，不按视口缩放字体。主要文字 `--ink` 为 `#18231e`，正文 `--text`
为 `#34453b`，辅助文字 `--muted` 为 `#56645c`，深绿色品牌 `--brand` 为 `#205b42`。
画布为 `#f2f5f3`，内容表面为白色。标题使用 `balance`、摘要和卡片标题使用 `pretty` 排版；
长仓库名仍保留换行点及必要断词，截图复核不能被 CSS 声明替代。

| 颜色用途      | 语义变量                                                           | 使用约束                                     |
| ------------- | ------------------------------------------------------------------ | -------------------------------------------- |
| 成功          | `--success` / `--success-soft` / `--success-border`                | 成功徽标、通知和行内反馈共用；与品牌绿色关联 |
| 运行 / 新观察 | `--info` / `--info-soft` / `--info-border`                         | 有明确状态文字或图标，语言标签不使用此色     |
| 需要注意      | `--warning` / `--warning-soft` / `--warning-border`                | 部分失败、原文已更新及警告标签共用一套琥珀色 |
| 失败          | `--danger` / `--danger-soft` / `--danger-border`                   | 失败徽标、错误横幅和错误文字共用             |
| 来源识别      | `--source-github-*` / `--source-arxiv-*` / `--source-hackernews-*` | 保留来源身份配色，不代表任务成功、警告或失败 |
| 交互          | `--brand-border` / `--border-interactive` / `--selection`          | 选中导航、控件悬停和文本选择                 |

颜色同时配合文字，不能仅凭颜色表达状态。证据说明使用中性浅底和正文色，
不能因包含证据或局限文字就将整个区块自动渲染成警告。
密钥「已配置」使用中性文字，仅「未配置」使用警告色；配置存在不等于接口验证成功。

普通正文在实际背景上的对比度至少 4.5:1。不可交互的禁用控件可以降低透明度，
不能以整张卡片变淡表示已读。既有来源图片继续使用，不增加装饰性素材和渐变。

中文摘要进度放在系统设置的平面分区，使用开关选择范围，三列描述列表显示真实状态数量；标签 14px、数字 24px。
缺摘要的卡片保留原始标题与原文入口，摘要区域显示中文待生成 / 处理中 / 失败提示，不把英文正文截断后充作中文摘要。
生成状态不改变来源、已读态、技术筛选资格和真实增长指标；无法生成时保留缺失和错误，不以占位文案冒充成功摘要。

## 布局与密度

| 表面     | 变量               | 用途                                                   |
| -------- | ------------------ | ------------------------------------------------------ |
| 页面画布 | `--canvas`         | 整个工作区背景                                         |
| 白色内容 | `--surface`        | 项目 / 推荐卡片、输入控件、表格正文与弹窗              |
| 轻底色   | `--surface-soft`   | 侧栏、研究偏好和推荐设置的平面区域                     |
| 浅沉底   | `--surface-inset`  | 展开的设置标题、只读配置、证据说明、缺失指标与普通标签 |
| 表头     | `--surface-header` | 与白色数据行明显区分                                   |
| 悬停     | `--surface-hover`  | 表格行和中性控件的反馈                                 |

表头和行悬停只通过背景区分，不增加阴影。卡片保留基础 / 悬停两档轻阴影，表单分区不做悬浮卡片。

- 侧栏 232px，顶部栏 56px；内容区最大 1800px、左右 28px、上方 24px，居中使用可用宽度。
- 间距以 4px 为基本刻度，使用 `--space-1` 至 `--space-8` 和 `--space-10`（4–32px、40px）；
  标签和小型控件允许 `--space-half`（2px）。图标尺寸、边框和按图标对齐的偏移不等同于布局间距。
- 页面标题与操作区顶部对齐；分区计数和链接按标题第一行行高居中，不使用额外顶部内边距凑齐。
- 技术推荐顶部使用可换行的栏目标签栏：精选、项目、模型、工具、工作流、讨论、论文、官方、发现。
  选中项使用白色表面、加粗品牌文字和清晰边框；标签显示当前采样条数而不是来源总量。
  1024px 宽度允许换成两行，不横向隐藏后续分类；标签栏在页面滚动时吸顶。切换栏目保留技术主题参数。
  默认「精选」纳入项目与资讯，按资讯 ID 去重后最多展示 12 条；项目优先保留两席，资讯按栏目份额轮取，
  近期未展示的候选优先，保留栏目内部顺序，不跨来源比较热度分。资讯不足时其余项目可补空席。
  一次只展示一个栏目的完整卡片，不再纵向堆叠所有分区。
- 技术推荐以内容栏目与技术方向入口进行导航，技术方向使用真实链接，选中项带 `aria-current=page`，
  `topic` 与 `tab` 同时保存在 URL。直接展示前六个方向与当前选择；「更多方向」使用现有 Dialog 展示后台分组目录与搜索，
  宽度最多 760px，内部按两列分组，可用键盘、Escape 与焦点恢复。不能把主题目录数量冒充候选内容数量。
- 首页仅保留可展开的研究偏好；数字条数、方向权重和重复观察窗口移至「系统设置 → 高级推荐设置」，默认折叠。
  普通分类导航不写推荐策略或来源配置，不要求保存数字参数。删除原首页双列设置布局。
- 紧凑卡片使用
  `auto-fit / minmax(330px, 1fr)` 网格，标题 18px 两行、摘要 16px 两行、推荐依据 13px 两行。
  卡片只减少重复证据，不隐藏已读态、来源内指标或原始链接。
- 资讯库在标题下提供全部、模型、工具、项目、工作流、论文、数据集标签，搜索、来源和排序位于同一工具行。
  分类面板默认收起以先显示资讯；面板标签本身可点击展开。URL 中的发布团队、主题或分类变化时恢复对应面板，
  用户手动收起后，排序等无关参数变化不会强制展开。切换内容标签清理平台排序自动附带的来源，保留显式来源筛选。
- 栏目标签通过 `aria-controls` 指向内容区，内容区使用 `role=tabpanel` 和 `aria-labelledby` 关联当前标签。
  左右方向键循环选择，Home / End 移至首尾，并同步键盘焦点；重复使用组件时内容区 ID 必须唯一。
- 项目网格采用 `auto-fit / minmax(330px, 1fr)`，列间距 16px。
  1024、1440、1920px 桌面窗口有足够记录时分别可显示 2、3、4 列。
  只有一个项目时占满整行，简介与增长指标在卡片内分列；不添加假项目填空。
- 资讯库保留列表及 268px 统计侧栏；设置使用比例列，不限制在狭小左列。
- 卡片圆角 `--radius-card` 为 8px、内部间距 20px；控件 `--radius-control` 为 6px、标签 `--radius-tag` 为 4px。
  只为重复资讯、项目、弹窗和真正独立的工具使用容器，不嵌套卡片。
- 表格保持可读字号，宽度不足时仅表格容器横向滚动，页面本身不横向溢出。
- 搜索与输入高 40–42px，图标按钮和图标链接共用 `--icon-button-size`（34px），弹窗关闭按钮同规格。
  长标题、错误和指标可换行，禁止挤压相邻控件。

## 项目卡片与交互

项目名、中文简介、技术分类、增长状态优先可见。指标区区分短期获星、窗口平均速度与累计
Stars；关注理由直接展示后端首条理由，完整依据、代码证据、统计窗口保留在可展开区域。
UTC 日获星不能改成滚动 24 小时；缺失值继续显示待观测、未知或待积累。

组件约定：

- 推荐卡、项目卡和资讯列表共用阅读标记：实心深绿点为未读，空心点为已读，均有可访问名称。
  已读标题使用 `--text-read`，悬停与键盘焦点仍保留交互反馈；摘要、指标和整卡透明度不变。
  阅读状态来自已有 API 的 `is_read`，不能以「近期已展示」替代「已读」。
- 主指标固定三列、展开的 24h / 7d 指标固定两列，用细分隔线区分。标签预留两行高度，数值起点对齐。
  累计 Stars 按完整数值保留列宽，避免六位数被拆行。短期增长以字重强调，正值使用品牌绿，
  所有主指标均为 24px；零值、负值保留实际数值。
- 缺失增长使用静态浅底占位块，保留待观测、未知、待积累的原意；不使用加载动画，也不填零。
- 加速上升 / 快速增长为绿色，使用不同 Lucide 图标及文字；新项目观察为蓝色，持续跟踪为中性色。
  语言标签使用中性色，不承担增长状态语义。新观察底色使用 `--info-soft`。

按钮、链接和卡片提供边框/颜色反馈，统一使用 `--duration-fast`（140ms）和
`--ease`（`cubic-bezier(0.2, 0, 0, 1)`）；开关滑块采用同一时长和曲线。
键盘焦点为深绿色轮廓；不添加位置移动和循环装饰动画。
只有真实加载使用旋转图标，并遵循减少动画的系统设置。图标使用现有 Lucide 与可访问名称，
复杂控件保留 Radix/shadcn 交互。GitHub 图标外链与收藏按钮共用提示组件，支持悬停和键盘焦点。
研究偏好显示真实已选数量和主题，展开后保留保存操作。
选中技术方向后，分区标题显示当前方向；进入模型资讯或项目列表时保留方向参数。

加载状态用 `role=status` 和 `aria-busy` 标识；空状态不能冒充成功数据；错误以 `role=alert`
展示实际原因。仅无数据时显示空列表提示，不能将请求失败误报为无数据。

## 验证

`npm --prefix frontend run build`、`npm --prefix frontend test` 和
`npm --prefix frontend run test:e2e` 是本次前端验收入口。桌面视觉用例读取实际运行的后端，
在 1024、1440、1920 × 1000 窗口检查八个路由的字号、选定文字对比度、标题/动作对齐、
表头 / 行悬停层次、网格列数、单卡宽度、页面溢出与浏览器异常。
项目交互用例另检查图标目标尺寸、提示、键盘焦点和减少动态效果设置。
真实数据截图在忽略的 `.runtime/ui-desktop-*`；本批审阅使用 `docs/images/workbench.png` 与
`docs/images/models.png` 的实际运行截图。
加载/空数据/错误另使用浏览器请求夹具，不写入数据库；视觉检查不等于完整无障碍认证。
实际执行结果维护在 [历史验收记录](validation-history.md)，执行方法见 [testing.md](testing.md)。
