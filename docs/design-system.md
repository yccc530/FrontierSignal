# 桌面工作台视觉规范

适用于技术推荐、项目库、资讯库、收藏、来源、任务、设置和详情弹窗。
只支持电脑浏览器，工作区最小宽度 1024px；不增加手机导航、手机样式和手机测试。
布局与样式可调整，API、排序、筛选、收藏、已读、任务及模型配置遵循现有业务契约。

## 字体与颜色

统一变量定义在 `frontend/src/index.css`，推荐与项目布局使用 `frontend/src/discovery.css`。
新增界面优先引用语义变量，不追加局部浅灰或小字号覆盖。

| 用途 | 字号 | 约束 |
| --- | --- | --- |
| 页面主标题 | 30px | 700 字重，1.3 行高 |
| 分区标题 | 20px | 650 字重 |
| 项目和资讯标题 | 18px | 650 字重，允许长名称换行 |
| 正文、中文摘要 | 16px | 1.7–1.85 行高 |
| 表格内容、输入控件 | 15px | 不压缩到辅助字号 |
| 表单标签、按钮、关注理由 | 14px | 关键动作保持清晰 |
| 时间、来源、状态、标签 | 13px | 常规文字的最小字号 |
| 项目指标 | 24px，正增长 28px | 等宽数字；未知与零保持区别 |

字体使用 Inter、Segoe UI、Microsoft YaHei 和系统无衬线回退，不请求外部字体。
字间距为 0，不按视口缩放字体。主要文字 `--ink` 为 `#18231e`，正文 `--text`
为 `#34453b`，辅助文字 `--muted` 为 `#56645c`，深绿色品牌 `--brand` 为 `#205b42`。
画布为 `#f5f7f6`，内容表面为白色。蓝色用于待观察与运行状态，琥珀色用于部分失败，
红色用于错误。颜色同时配合文字，不能仅凭颜色表达状态。

普通正文在实际背景上的对比度至少 4.5:1。不可交互的禁用控件可以降低透明度，
不能以整张卡片变淡表示已读。既有来源图片继续使用，不增加装饰性素材和渐变。

## 布局与密度

- 侧栏 232px，顶部栏 56px；内容区最大 1800px、左右 28px、上方 26px，居中使用可用宽度。
- 项目网格采用 `auto-fit / minmax(330px, 1fr)`，列间距 16px。
  1024、1440、1920px 桌面窗口有足够记录时分别可显示 2、3、4 列。
  只有一个项目时占满整行，简介与增长指标在卡片内分列；不添加假项目填空。
- 资讯推荐分区使用双列，分区之间 24px；分区自身不套卡片。
  资讯库保留列表及 268px 统计侧栏；设置使用比例列，不限制在狭小左列。
- 卡片圆角 8px、内部间距 18–20px；控件圆角 4–6px，边框与轻阴影区分表面。
  只为重复资讯、项目、弹窗和真正独立的工具使用容器，不嵌套卡片。
- 表格保持可读字号，宽度不足时仅表格容器横向滚动，页面本身不横向溢出。
- 搜索与输入高 40–42px，图标按钮 34px；长标题、错误和指标可换行，禁止挤压相邻控件。

## 项目卡片与交互

项目名、中文简介、技术分类、增长状态优先可见。指标区区分短期获星、窗口平均速度与累计
Stars；关注理由直接展示后端首条理由，完整依据、代码证据、统计窗口保留在可展开区域。
UTC 日获星不能改成滚动 24 小时；缺失值继续显示待观测、未知或待积累。

按钮、链接和卡片提供边框/颜色反馈；键盘焦点为深绿色轮廓；不添加位置移动和循环装饰动画。
只有真实加载使用旋转图标，并遵循减少动画的系统设置。图标使用现有 Lucide 与可访问名称，
复杂控件保留 Radix/shadcn 交互。研究偏好显示真实已选数量和主题，展开后保留保存操作。

加载状态用 `role=status` 和 `aria-busy` 标识；空状态不能冒充成功数据；错误以 `role=alert`
展示实际原因。仅无数据时显示空列表提示，不能将请求失败误报为无数据。

## 验证

`npm --prefix frontend run build`、`npm --prefix frontend test` 和
`npm --prefix frontend run test:e2e` 是本次前端验收入口。桌面视觉用例读取实际运行的后端，
在 1024、1440、1920 × 1000 窗口检查七个页面的字号、选定文字对比度、标题/动作间距、
网格列数、单卡宽度、页面溢出与浏览器异常。真实数据截图在忽略的 `.runtime/ui-desktop-*`。
加载/空数据/错误另使用浏览器请求夹具，不写入数据库；视觉检查不等于完整无障碍认证。
实际执行结果维护在 [testing.md](testing.md)。
